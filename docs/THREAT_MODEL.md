# 暂定黑盒威胁模型

当前仅将本研究记为黑盒环境。现实部署、可观测接口及后续攻击预算的完整定义，待用户进一步确定；本文不将尚未明确的内容补写为已验证事实。

## 暂时沿用的边界

- 攻击发生在公开商品目录阶段。攻击者只能修改自己的商品展示图片，不能修改公开商品名称或其他商户的商品。
- 攻击者不能读取或修改受害者的长期记忆，包括未来可能关联到自己商品的购买记录。
- 攻击者不知道未来正式请求、购买操作、观察轨迹、成交价格、奖励及其他历史。
- 公开图对选取与生成仅使用目标和自有候选的公开图片、公开名称、公开原图标注和本地公开代理。不能访问私有类目树、下游模型概率或正式检索名次。
- 不通过探测受害系统来挑商品、图对、阈值、种子或图片。不向目标平台发送训练探针。
- 评估模型权重、图文比例和检索阈值不作为攻击者的已知事实。感知优化中的等权联合目标只是固定代理假设，不能据此声称攻击者知道受害检索器参数。

## 评估端职责

最终图片冻结后，评估端才能读取同一个共享长期记忆池和正式模糊图文查询。替换一个副本内的商品图片，仅模拟该商品以修改后的展示图被正常购买并入库；不赋予攻击者记忆读写权限。基础共享池始终只读，真实商品名称及完整历史保持不变。

默认所有任务和两种方法都面对完整共享池，不建立每组十五条的孤立库。检索键使用商品图片及其真实公开名称，默认各半；查询使用独立模糊图和泛指文本，默认各半。完整购买历史只在检索后展示。评估比例属于研究端设置。

默认评估编码器独立于两个方法生成时使用的代理，并拒绝直接复用同名同预训练的代理作为正式留出评估器。模型实现、权重摘要和图像解码身份写入评估记录。该约束有助于避免同模型验证，但不足以证明对任意未知现实系统可迁移。

## 仍需如实披露的限制

公开视觉特征包含语义及纹理，并非严格的物理拓扑描述；文本相似不证明两种商品具有可互替用途；低试改色代价也不证明完整生成可行。筛选分数不能解释为成功概率。

原感知优化算法及默认参数来自既有研究实现，本次迁移没有重新证明其历史开发过程符合一个尚未完整定义的黑盒协议。后续正式研究须明确开发集、代理来源、目标模型关系及冻结顺序，不把迁移本身当成黑盒有效性实验。

文件访问审计用于发现可复现运行中的越界读取，不是抵御恶意本地代码的操作系统沙箱。公开来源和攻击者所有权由显式清单声明，不能由代码自动证明。

模糊查询图片须独立生成，且不能出现明确商品名称、品牌名称或可识别商标。目前只实现输入约定与核对门槛，未实现图片生成，也未将元数据声明当成自动视觉认证。
