# 两种方法

公开方法只有 lucid（原始像素优化方法）和 PerLAGE（感知标签保护生成编辑方法）。统一分派入口不再接受旧自然方法名称，也不使用会对不同方法集合返回相等的兼容容器。

## 原始像素优化

保留三个公开代理、全局与局部特征目标、最优传输及像素投影。默认执行一千步，最大像素预算为十六级。完整商品标题监督能力保留为显式参数，默认仍为纯图片目标。内部优化引擎的原方法代号仅作引擎实现细节，对外完成记录统一为当前方法名。

真实引擎和编码器已内置到依赖目录，无需导入原项目或相邻项目的源码。模型权重仍通过明确的公开模型配置和本地缓存定位。

## 感知标签保护生成编辑

保留原感知优化实现的计算步骤和默认数值：主体分割、前景统计选色、印刷区保护颜色融合、生成潜变量细化。生成初始化是内部步骤，不是独立最终方法；不能只执行改色或像素补偿便宣称完成。

最后阶段默认六十步，潜变量级数二十四，学习率百分之一，结构相似度下限为百分之八十五，平均像素变化上限十二级，回退搜索八级，期望代理得分增益百分之二，特征保持权重百分之二。上述数字是继承的实现默认值，不能解释为通用人类感知界限，也不保证检索成功。

本次没有用新项目的私有评估调参，也没有继承原实验图或初始化断点。新完成记录要求四阶段文件内容摘要、实际请求与完成步数、本次独立初始化身份以及最终图片绑定全部通过；缺少一项则不能作为完整成图。

## 共用策略与共享池

两种方法都先用相同公开候选集和相同选取代理挑选图对，再按参数分派生成。正式共享长期记忆池只在最终图片冻结后由评估端读取。共享池的扩充只改变检索候选空间，不向生成或公开图对选取暴露任何受害记忆。

本项目不把共享长期记忆池当作训练竞争池。感知方法继续不使用影子池，也不因共享池缺失而自动更换方法。原始像素方法同样不读取记忆池训练。
