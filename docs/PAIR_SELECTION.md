# 公开图对选取方案评审与实现

用户提供方案的可用核心，是先以公开商品图和公开名称在本地筛选图对，避免依赖受害者私有类目、记忆库或目标模型探针。两种方法均采用这一步。实现没有继承材料中的保证性表述和未经测量的示例数字。

## 文献与论断核对

材料将 Vis-Poison（视觉知识投毒论文）写为二〇二四年会议成果；[作者公开论文页](https://arxiv.org/abs/2608.20756)的提交日期为二〇二六年八月，作者标注为同年的自然语言处理会议研究发现论文集。不能沿用材料中的年份，也不能把该论文集自动写成主会的中国计算机学会分级。

MetaPoison（元学习数据投毒方法）的[正式会议页面](https://proceedings.neurips.cc/paper/2020/hash/8ce6fc704072e351679ac97d4a985574-Abstract.html)属于二〇二〇年神经信息处理系统大会，描述了跨受害模型迁移；该来源不能为材料所述“测地距离可筛出迁移率最高图对”或某个固定相似度阈值提供证明。因此新实现把选取规则标为待公开开发集校准的启发式机制。

## 四个分项及优化

**几何代理。** 使用 DINOv2（自监督视觉编码器）的全局特征与前景图像块特征。基于公开原图的主体分割先屏蔽背景，显式文字与品牌区域也被屏蔽。局部相似度改为两个方向各自平均最大余弦后再取平均，可比较不同数量的前景块；对前景长宽比差异施加柔性惩罚。原材料的公式只有一个方向，不能称为双向匹配，也不是最优传输或测地距离。[模型实现来源](https://github.com/facebookresearch/dinov2)公开提供全局和图像块表示。

**语义窗口。** 使用本地通用句向量计算公开商品标题相似度，再经过高斯窗口。默认中心为零点七二、标准差零点一二，允许区间零点五五至零点九。这是初始配置，不是跨模型通用常数。窗口得分仅为语义代理，不能证明洗手液可替代洗发水等消费用途判断。

**跨模态余量。** 使用本地公开图文编码器比较“目标图配目标标题”和“目标图配源商品标题”的余弦差，再以指数函数衰减。代理只估计一般图文违和程度，不能推断受害大模型实际思维链或自纠偏概率。

**试改色代价。** 不直接将两个不同商品原图的 LPIPS（学习感知图像块相似度）距离解释为可编辑成本。实现对源商品非文字前景施加固定四分之一色度偏移，保留明暗、结构、文字和背景，再测量源图到该试改色图的感知距离，并使用指数映射得分。此探针与后续方法无关，两种方法使用同一排序；它仍不能取代完整生成的质量检查。[感知度量官方实现](https://github.com/richzhang/PerceptualSimilarity)提供了度量本身，并未保证原图间距离能预测本项目的生成成功。

## 综合、门禁与冻结

四项分数按零点三五、零点三、零点二五、零点一的归一化权重在对数空间求和，再指数还原。使用对数可避免直接连乘下溢；稳定并列时按公开商品标识排序。

硬门禁包含：明确的攻击者所有权声明、排除相同商品标识、排除归一化后同名、排除相同图片字节、排除近重复语义标题、几何下限和语义区间。形态下限默认零点六五，近重复标题阈值默认零点九五。没有候选合格时，保存全部拒绝原因并停止，不降低门槛。

公开候选、图片摘要、标注、选取配置、代理权重身份、各候选分项及最终图对一次冻结。后续感知方法或像素方法复用同一选取结果；不因私有名次或方法差异重新选图。复用时重新核对公开输入及代理权重内容。

确定图对后，程序将其发布到 `src/data/public/groups/<组名>/`（公开分组目录），使用 `source`（原商品）和 `target`（目标商品）文件名，保留原图片格式及字节。正式完整流程配置直接指向该目录的图对清单，供两种方法复用。数据集粗筛、实际审核、正式文件位置及具体命令见 [公开数据入口](PUBLIC_SELECTION.md)。

后续可优化的主要工作是用**独立公开开发集**校准各项量纲和门槛，衡量不同代理之间排序的一致性，并单独核对商品用途兼容性。正式私有记忆与测试请求不参与这些调整。当前没有添加复杂多代理集成或额外目标交互，也没有声称已用实验验证这些启发规则的收益。
