# 第六、七组无像素感知约束放宽实验

本轮只新增独立实验接口，不改变原感知方法、无像素感知方法及统一方法分派。仅测试第六组牛仔裤、第七组洗发水，不调用购物或远程决策模型。

入口：`tools/run_perlage_relaxed_groups67_20261111.py`。默认输出：`output/perlage_relaxed_groups67_20261111`。独立生成接口：`src.visual._perlage_no_pixel_relaxed.generate_relaxed_no_pixel`。

## 生成控制

使用十一月九日基础包的同一商品图对、公开源商品名称及原目标特点训练正文，每组保持原来的一条训练句。先核验旧完整无像素生成记录、输入及三个阶段的图片摘要，复用其分割、目标前景统计和印刷区保护颜色融合结果，再独立执行完整第四阶段。它是“复用已完成前缀后的独立细化实验”，不能描述成重新执行全部四阶段。

两档设置在正式检索前冻结，不读取正式询问、查询照片、共享池或名次训练，不以正式名次挑种子、图片、检查点或更换参数。检查点选择只依据同一公开训练目标及质量限制。原始产物保持只读。

|设置|原最终细化|放宽档|强放宽档|
|---|---:|---:|---:|
|自身特征保持权重|0.02|0|0|
|目标|相对初始化图的平滑增益保留损失|直接最大化普通联合得分|直接最大化普通联合得分|
|潜变量细化步数|60|160|240|
|结构相似度下限|0.85|0.75|0.65|
|平均绝对变化上限，像素级|12|24|40|
|潜变量解码图像变化上限，像素级|24|64|96|
|潜变量幅度上限|0.5|1|2|
|初始学习率|0.01|0.02|0.03|
|宏观平方惩罚|0.001|0.00005|0.00005|
|宏观总变差惩罚|0.003|0.0003|0.0003|
|净化路径损失权重|3|0|0|
|像素优化和固定辅助残差|0|0|0|

训练方向仍为目标图和原训练文字各半，保持原公开源商品名称形成的联合键。新目标为联合得分均值与软最小值各半，不再以“初始化得分加0.02”作为软阈值。原来的0.02是余弦分数绝对增量，并非相对百分之二；参照图是初始化生成图，并非源商品原图。

本轮只评估无防御，因此去掉净化路径的保留目标及相应检查点优先级，直接优化普通图像路径。只加载原本地变分自编码器进行潜变量解码，保留前景编辑与印刷区锁定。光晕限制从原先的“原光晕一半与6取大值”放宽为“原光晕与12取大值”。第三阶段生成、颜色融合及其原门槛保持本次复用前缀的原设置。

## 检索和独立复核

四张完整图片全部冻结后，评估进程才打开基础包的一百八十九条共享记忆及十一月十日的特点文字加独立模糊照片正式输入。每组二十条文字和该组冻结照片不变，查询图文各半、记忆图文各半。指定编码器与训练代理重合，不能声称独立留出黑盒迁移。每组正式文字有一条与训练正文精确重合，报告如实保留这一局限。

四个条件分别为原图库、原无像素方法图、放宽档、强放宽档。每个条件仅构造一个完整全局库，两组源条目图片同步替换，其余条目及全部文字不变。原方法对照也只替换这两组图片，避免与“其他七组也修改”的历史条件混淆。共一百六十条完整排名、三万零二百四十个候选分数。独立进程新建显卡编码器复算全库，检查排名、图片身份及全部分数。

自动报告第一、前三、前五比例，平均名次、平均倒数名次，以及相对原图库和原方法的配对增量。不承诺一定显著提高，不因结果不理想重采样。两组四十个相关请求的开发实验不能视为九组总体效果或独立统计重复。

## 运行、暂停及恢复

在项目根目录使用现有环境运行：

```powershell
.venv/Scripts/python.exe -X utf8 -B -u tools/run_perlage_relaxed_groups67_20261111.py
```

队列各阶段为独立子进程，按档位与组别顺序串行；生成中保存潜变量及优化器断点。技术失败保存日志并停止。重新运行相同命令会核验身份，复用已完成图片，从未完成处继续，不覆盖有效结果。

本轮根目录创建 `PAUSE_REQUESTED` 文件可请求在下一生成步或阶段边界暂停。明确恢复时移除本轮暂停文件，再执行同一命令。此文件与旧购物实验暂停标记完全独立。旧购物暂停与检查点摘要会持续核验，本轮没有恢复购物入口。

状态位于 `RUN_STATUS.json` 和 `RUN_STATUS.md`；每张图的 `progress.json` 保存细化进度，阶段日志位于 `logs`。完成后自动写 `REPORT.md`、`SUMMARY.json`、`INDEPENDENT_VERIFICATION.json` 和 `COMPLETED.json`。
