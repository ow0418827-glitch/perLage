本轮入口为 `tools/run_perlage_rankfocus_groups67_20261111.py`，输出位于 `output/perlage_rankfocus_groups67_20261111`。只使用第六组牛仔裤、第七组洗发水，完整执行每张图的一千步潜变量优化。复用同组已核验的分割、目标前景统计选色和印刷保护颜色融合前缀，不能将其写成重新生成全部前三阶段。

## 上轮核查和优化动机

上轮放宽实验有完整四图冻结记录、训练访问审计及一百六十排名/三万零二百四十候选分数独立复算证书。指标仅有限改善：原方法两组平均名次12.95，强放宽档11.8；前三和前五均零。具体核验结果另保存在本轮 `audit_previous.json`。

上轮强档洗发水240次更新中206次拒绝，最终光晕值12.853接近上限12.862；结构相似度仍0.927，平均变化仅5.578级。牛仔裤强档全部240步接受，但实际结构相似度0.915、平均变化8.304级，距放宽后的预算仍远。这说明仅放宽结构相似度和平均变化上限，无法解除所有限制。

另一关键差异是训练联合键只编码源商品名，正式检索键却编码源商品名称、品牌、完整属性和特点正文。新接口从源商品自己的冻结公开定义、公开正文及已审查特点重建完整键；训练进程不读取共享记忆、正式询问或查询照片。目标训练句逐字保持上一轮唯一的特点正文。

## 本轮改动

1. 使用自身真实公开全文键构造可微联合目标，图文比例及编码方式与正式检索一致。不得把目标商品属性写到源商品。
2. 在原“目标图片与训练特点文字各半”的方向上，增加解析补偿后的图像特征教师。补偿只使用公开目标图、训练句和源商品自己的公开文字，不包含竞争库或正式排名。
3. 潜变量工作分辨率从256提高到512，两档完整优化1000步；解除潜变量平滑和平方保持惩罚，扩大潜变量幅度及解码后的图像变化预算。
4. 将可编辑区域扩大到完整源商品前景，保留印刷保护区锁定与边界羽化。取消光晕硬拒绝，保留实际光晕指标及轻量软约束。
5. 保持变分自编码器潜变量更新；不优化像素参数，不添加固定像素残差，不调用净化噪声网络。

正式评估继续使用原二十条特点文字和对应独立模糊照片；每组二十请求、图文各半、同一指定编码器、完整一百八十九条共享库、仅无防御。训练代理与指定编码器重合，不能称为独立留出黑盒迁移。

六个库分别为原图库、原无像素感知方法、原始像素方法、上一强放宽档和两档新图。每个库都只有一个完整共享池，同时替换两组源条目，其他一百八十七条与全部文字保持一致。原始像素对照也按此范围重新编码检索，避免与其他七组也改图的历史条件混淆。

本轮沿用两组作为开发实验，用户和实现者已看过其先前评估表现；不能将新结果宣称为未经调参接触的独立测试集。每组二十条正式文字有一条与训练正文精确相同，也须如实披露。

## 后台运行

```powershell
.venv/Scripts/python.exe -X utf8 -B -u tools/run_perlage_rankfocus_groups67_20261111.py
```

各阶段独立子进程串行执行，技术失败保存日志并停止，重新运行相同命令即可核验身份、跳过完整图片、从未完成潜变量断点续跑。阶段状态保存在 `RUN_STATUS.json`，各图进度在对应 `generation` 目录的 `progress.json`；完成后自动生成 `REPORT.md`、`SUMMARY.json`、`INDEPENDENT_VERIFICATION.json` 和 `COMPLETED.json`。

本轮根目录的 `PAUSE_REQUESTED` 文件可请求暂停，移除后以相同命令恢复。本轮没有购物入口，也不改变旧购物标记。
