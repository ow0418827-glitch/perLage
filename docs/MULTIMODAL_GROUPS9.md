# 九组特点文字加独立模糊照片复测

本轮复用十一月九日两种方法的完整冻结成图、各组完整一百八十九条记忆库及二十条正式特点文字。按用户同日晚间追加要求，先串行完成两种方法的检索和独立复算，比较错误源记忆进入前三、前五的比例，再决定是否购物。已确认十一月十日原图库基础购物对照一百八十次全部结束并退出，才启动本轮。

查询照片保留商品类别和一般外形，不出现品牌、可识别品牌标志或可读商品名。每组一张，两种方法及组内二十请求共用。照片由内置图像生成工具独立生成，逐张实际视觉核对，首次有效图直接冻结，不通过正式排名挑图。生成原始字节、完整提示词、审核和摘要均保存在本轮独立输出中。

查询及记忆检索键均按图文各半编码；纯文字模式仍可通过通用接口显式选择，图文缺图或摘要改变时停止。正式文字、任务编号逐条核对基础包及两个方法上一轮实际评估计划，图文转换保留正文摘要与训练重合记录。

- 本轮目录：`output/groups9_multimodal_20261110`。
- 入口：`tools/run_groups9_multimodal_20261110.py`。
- 查询图片与生成审核：本轮目录的 `input_resources/query_images/<组键>/query.png` 及旁边的清单。
- 固定输入计划：`EXPERIMENT_PLAN.json`（实验计划文件）。
- 总状态：`RUN_STATUS.json`（运行状态文件）；实际子进程与阶段见 `ACTIVE_CHILD.json`（当前子进程文件）。
- 阶段日志：`logs/<方法>_<阶段>.log`。
- 每方法结果：`methods/<方法>/REPORT.md`（分方法报告），购物记录与逐次推理位于对应购物子目录。
- 总结果：完成后自动写根目录的 `REPORT.md`（总报告）及 `COMPLETED.json`（完成标志文件）。

每方法检索包括原图库和修改图库，共三百六十个全库排名。独立进程新建同一显卡编码器，不读取首次向量，复算六万八千零四十个候选分数，核对名次、商品及图片身份后才放行购物。购物采用本轮已经独立核验的图文向量重新排序，缺失缓存即停止，不读取旧纯文字查询向量。

购物只测试各方法修改库，九组各二十次，每方法一百八十次，总计三百六十次。沿用原模型、中性指导、三条记忆和商城页面图片未加入策略视觉输入的观察协议。每次真实请求先核对当前特点文字、查询图及三条记忆图的实际字节摘要、顺序、模型和参数；有效记录恢复时跳过，不按购买结果重采样。

模型实际返回的推理正文和结构字段保留在会话记录中，并额外导出阅读文件。失败证据保留，技术故障停止当前队列；在核查锁与真实进程后，重新运行相同入口即可从未完成阶段恢复，不重复已保存的有效会话。可用准备参数 `--prepare-only`（仅准备及校验）先核对冻结资源，不执行编码或模型调用。

原定北京时间十一月十一日凌晨三点的检查自动化曾在等待比较时暂时停用。购物实际提交前三条记忆，因此以无像素感知方法修改库的一百八十请求总体前三召回率作为放行主判据；前五比例同时列出。新图文前三比例未严格高于上一轮纯文字（包括持平）时，暂停两方法后续购物，不得通过重选输入或重采样改变比较结果。根目录存在 `SHOPPING_PAUSED.json`（购物暂停标记文件）时，所有购物阶段均禁止启动。即使移除标记，也必须通过实际计数、固定计划及全部证据文件摘要检查。原冻结计划保持原字节，执行范围另写修订记录。
