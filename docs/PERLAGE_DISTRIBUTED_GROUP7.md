# 第七组主体与背景分布编辑先导实验

本轮最终授权范围仅为第七组洗发水目标组，不启动牛仔裤，不自动追加任何其他组。原无像素感知方法、上一轮放宽与强攻方法及其全部产物均保持只读。

独立入口：`tools/run_perlage_distributed_group7_20261111.py`。新方法包：`src/visual/_perlage_no_pixel_distributed`。输出：`output/perlage_distributed_group7_20261111`。

## 要验证的问题

上一轮把变化限制在商品主体，使表面出现明显的彩色碎纹。本轮允许背景一起承担检索表示变化，同时降低主体局部变化预算，比较是否能在更小主体失真下保持排名。背景编辑不保证自然度，必须独立报告背景平均变化和纹理变化，不能用全图平均值掩盖主体失真或把伪影转移到白背景。

## 固定的三个条件

|条件|主体变化预算，像素级|背景变化预算，像素级|前景相对原图结构相似度下限|前景相对原图平均变化上限|背景相对原图平均变化上限|
|---|---:|---:|---:|---:|---:|
|仅主体对照|24|0|0.85|10|4|
|主体加背景均衡档|24|12|0.85|10|4|
|主体加背景较宽档|48|24|0.80|16|6|

像素级变化预算相对冻结颜色融合起点；分区域质量指标相对源商品原图。两种参照必须分别记录。仅主体对照和均衡档用于比较编辑范围的贡献，其余训练规则、主体预算、质量约束一致；较宽档作为附加折中探索，不能据其结果单独归因于背景编辑。

三种条件均保持原公开图对、源商品真实完整特点键、同一条目标特点训练正文、训练代理、固定种子和512尺寸潜变量空间。使用真实全文键联合目标与解析补偿目标各半，保留印刷保护区域，不优化像素参数、不添加固定像素残差、不读取共享池或正式询问训练。

完整复用本项目原方法经摘要核验的分割、目标前景统计选色和印刷保护颜色融合前缀，本轮重新执行第四阶段。背景可编辑是本轮第四阶段的明确范围变更，不伪称旧方法一直允许背景变化。

## 边际收益与提前停止

旧记录显示后期公开训练得分增益减小。例如普通强攻洗发水的第500至1000步联合得分增量占全程约7.43%，最后100步联合得分增量约0.00451；公开组合训练效用的后500步增量占全程约5.40%。这不证明中间图片的正式排名也已经饱和，因为旧轮未评估中间检查点。

本轮预先固定上限1000步、最少300步、每20步检查、每100步形成增益窗口；连续两个窗口的公开训练效用增益均不超过0.004时，按规则完成并停止，否则继续至上限。停止规则与状态写入断点，恢复时不得重置耐心计数。实际完成步数、停止原因、窗口增益与完整证书全部保存，提前完成不能标为实际执行1000步。

所有图片和检查点只由公开训练目标及固定质量门槛选择，不能根据正式排名回头挑选停止点或图片。
