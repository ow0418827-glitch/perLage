# 第七组洗发水“商品主体完全同 PerLAGE_no_pixel ＋ 仅背景潜空间优化”实验报告

训练保持原有特点文字条件与自身公开全文键。商品主体前景像素与原无像素感知方法（`PerLAGE_no_pixel`）100% 逐像素完全一致（零额外改动），仅对背景区域执行 350 步潜空间平滑优化。
两个新档位两张完整图片全部冻结后，才读取完整 189 条共享池及正式查询，共八个全局完整库对照。
检索只用无防御条件，20 条既有特点文字加同一张独立模糊照片，查询和记忆均图文各半；没有执行购物。
