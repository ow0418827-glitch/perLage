# 第七组洗发水“主体完全同 PerLAGE_no_pixel ＋ 背景平滑自然过渡”单图实验分析（2026-11-11）

## 一、 实验配置与完成核验

- **实验目录**：`output/perlage_bg_smooth_shampoo_20261111`
- **生成范围**：仅测试第七组洗发水（`07_shampoo`）单张图片（`bg_smooth` 档，350 步）。
- **核心机制**：
  1. **商品主体 100% 锁定**：以 `PerLAGE_no_pixel` 最终成图 `adversarial.png` 为锚点，`latent_levels = 0`，瓶身主体及印刷区像素零额外改动（`fg_latent_max_levels = 0`）。
  2. **12 像素零斜率余弦边界过渡**：在瓶身轮廓向外 12 像素范围内采用余弦平滑爬坡 $w_{\text{bg}}(d) = \frac{1}{2}(1 - \cos(\pi \operatorname{clip}(d/12, 0, 1)))$，消除主体边缘的 2 像素硬断层。
  3. **明度／色度双尺度高斯平滑**：`bg_chroma_keep = 0.55` 压缩色偏，并对 `tanh` 后的明度与色度残差分别施加 $\sigma_{\text{luma}} = 2.2$ 与 $\sigma_{\text{chroma}} = 5.0$ 的二维分离式高斯滤波及色度全变分惩罚（`bg_chroma_tv_weight = 0.003`）。
- **独立复算核验**：9 个完整 189 条共享库（共 180 条排名、34,020 个候选分数）已由独立进程从零编码复算，最大分数误差为 `0.0`（`INDEPENDENT_VERIFICATION.json`）。

## 三、 核心原因诊断：为何“纯白抠图背景”在强平滑下难以独自承担高强度检索偏移？

1. **外观边界与色块显著改善**：
   - 相比上一轮 `fg_lock_bg24`，本轮 `bg_smooth` 的全图结构相似度由 **0.8574 提升至 0.9206**，背景平均改变量由 **7.81 级降至 5.20 级**（降低 33.4%）。
   - 12 像素余弦边界爬坡彻底消除了瓶身边缘生硬的 2 像素白边断层，双尺度高斯平滑消除了细碎的红／蓝／黄水彩斑块。
2. **纯白背景（RGB = 255）的视觉掩蔽效应极弱**：
   - 第七组洗发水源图是典型的电商**纯白底抠图商品图**（背景像素几乎全为 `255, 255, 255`，无任何自然场景纹理或阴影）。
   - 在纯白背景上，任何超过 10～15 级的局部明暗变化——即便经过高斯平滑变成柔和的灰／暖色云团——肉眼仍会察觉背景不够纯净（像背景纸上有淡淡的水渍或阴影）。
3. **平滑滤波对 `ViT-B-32` 视觉特征的物理制约**：
   - 评估编码器 `ViT-B-32` 将图像划分为 `32×32` 图像块（对应原图约 `71×71` 像素），主要依赖图像块内部的**中频边缘与局部对比度**提取语义特征。
   - 当商品主体被 100% 锁死（`0` 改动），且背景残差被 $\sigma_{\text{luma}} = 2.2$、$\sigma_{\text{chroma}} = 5.0$ 的高斯滤波器滤除中高频梯度后，训练联合得分上限从 `0.8785`（`fg_lock_bg24`）回落至 `0.8179`（`bg_smooth`），导致正式查询下的图文联合相似度均值（`0.7113`）未能跨过共享库前五门槛（`0.7345`）。

## 四、 研究结论与后续折中建议

本轮实验与前两轮共同构成了清晰的**“外观自然度（SSIM）— 检索排名（Mean Rank）”帕累托前沿**：
- 若**完全锁死主体（0 改动）且强平滑背景**（`bg_smooth`）：`SSIM = 0.9206` 最高，但纯白背景缺少高频特征载体，平均名次仅到 `10.25`；
- 若**完全锁死主体（0 改动）且允许背景中频纹理**（`fg_lock_bg24` / `fg_lock_bg36`）：前五达 `100%`、前三达 `65%～90%`，但纯白背景会出现肉眼可见的斑块；
- 若要**同时兼顾“背景干净无斑块”与“高检索进入前三／前五比例”**：由于商品瓶身本身具有高光、曲面阴影和色彩纹理（对微小扰动的视觉掩蔽能力远强于纯白背景纸），最优折中是将背景预算压低至极微弱的纯平滑漫射过渡（如 `background_levels = 6～8` 级，肉眼几乎仍为纯白底），同时在瓶身非文字区允许**经过空间平滑的轻量级潜空间微调（如 `latent_levels = 16～24` 级，配合余弦内缩柔化与高斯平滑）**，让瓶身曲面光影承担主要语义偏移，而非让纯白背景纸单独承担。
